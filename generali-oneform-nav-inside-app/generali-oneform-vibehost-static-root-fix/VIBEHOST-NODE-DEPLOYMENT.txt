Windows PowerShell (run from this extracted project folder):
1) Install Node.js 20+ (already used to run the package checks).
2) Install VibeHost CLI from the official VibeHost docs and restart PowerShell.
3) Authenticate: vibehost login
4) Inspect the app/runtime options in CLI and confirm Node runtime is available for this account.
5) Deploy the project root using the supported Node runtime: vibehost deploy . --app generali-oneform-tera-kinabalu --runtime node --build server
   (If this account does not allow the Node runtime, deployment is blocked; static ZIP cannot substitute.)
6) Verify the deployed app's URL and deployment status; do not call it production-ready until secrets,
   persistent Supabase, OAuth, and business workflows are configured and tested.
